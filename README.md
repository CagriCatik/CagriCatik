## About this GitHub

This GitHub is my **engineering lab**.

It contains larger engineering projects alongside experiments, technical notes, learning repositories, prototypes, and implementations of concepts I find interesting.

My work and interests span several engineering domains, but they are connected by a common theme:

> **understanding complex systems, implementing them, measuring their behaviour, and improving them through software, data, automation, and AI.**

Some repositories are mature engineering projects. Others are deliberately exploratory and exist because I wanted to understand a technology, algorithm, standard, or tool by implementing it myself.

AI-assisted development tools are also part of my workflow. I use them to accelerate implementation, refactoring, documentation, and testing while focusing primarily on **architecture, engineering constraints, verification, evaluation, and system behaviour**.

## Selected Engineering Projects

These projects represent some of the areas I currently find most interesting.

### [RadarTrackBench](https://github.com/CagriCatik/RadarTrackBench)

A reproducible experimental framework for **3D radar target tracking and state estimation**.

Topics include:

* Extended Kalman Filter
* Iterated EKF
* Unscented Kalman Filter
* Cubature Kalman Filter
* Cartesian Kalman-filter baselines
* nonlinear radar measurement models
* Monte-Carlo evaluation
* NIS / NEES consistency analysis
* PSO-based parameter optimisation
* robustness scenarios and statistical validation

---

### [FMT-MPC](https://github.com/CagriCatik/FMT-MPC)

Experimental autonomous-driving stack combining **sampling-based path planning and model-predictive control**.

Topics include:

* Fast Marching Tree planning
* collision checking
* trajectory generation
* curvature-aware reference generation
* kinematic bicycle modelling
* MPC
* OSQP / convex optimisation
* simulation and diagnostics


---

### [RAG-on-Databricks](https://github.com/CagriCatik/RAG-on-Databricks)

A Databricks-based reference implementation exploring an end-to-end **Retrieval-Augmented Generation** architecture.

Topics include:

* Delta Lake
* Unity Catalog
* Bronze / Silver / Gold data processing
* document extraction
* embeddings
* Vector Search
* MLflow
* model serving
* RAG pipelines

---

### [Agentic-Track](https://github.com/CagriCatik/Agentic-Track)

My experimentation space for modern **agentic AI engineering**.

Topics include:

* agents
* LangGraph
* tool use
* RAG
* routing
* evaluation
* state and memory
* security controls
* workflow orchestration
